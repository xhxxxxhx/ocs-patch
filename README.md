# 学习通 / 超星 刷课辅助脚本（Userscript）

两个配合 **OCS 网课助手** 使用的用户脚本，解决两件事：

1. **任务点完成后不跳下一章** —— 页面渲染慢导致点击落空时自动重试；长时间无进展按级自救。
2. **章节测验答错** —— 从成绩页读出正确答案后重做重填，循环到满分；题库没答案时按看门狗自动蒙题并交卷。

## 脚本说明

| 文件 | 作用 | 版本 |
|---|---|---|
| `cx-auto-next.user.js` | 任务点完成后自动跳下一章；跳转落空重试；连续 10 分钟无推进时：视频暂停→点播放、切学习测验、强制点下一节、整页刷新、红条告警 | 1.1.0 |
| `cx-quiz-retry.user.js` | 章节测验：读成绩页正确答案 → 重做 → 填对 → 再交，直到满分；题都选完 60 秒不交卷自动点提交；90 秒没人答题自动蒙一轮再交 | 1.6.0 |

## 安装

需要先装一个用户脚本管理器，二选一：

- [脚本猫 ScriptCat](https://scriptcat.org/)（推荐，Edge/Chrome）
- [Tampermonkey 篡改猴](https://www.tampermonkey.net/)

然后任选一种方式安装脚本：

**方式 1：从本仓库 raw 链接安装**

在浏览器安装好管理器后，直接打开对应文件的 raw 地址，管理器会弹出安装页：

```
https://raw.githubusercontent.com/xhxxxxhx/xxx/main/cx-auto-next.user.js
https://raw.githubusercontent.com/xhxxxxhx/xxx/main/cx-quiz-retry.user.js
```

**方式 2：本地导入**

下载 `*.user.js` 文件，拖进管理器的管理面板，或新建脚本后粘贴内容保存。

## 使用建议

- 两个脚本都是给 **OCS 网课助手** 打配合的，OCS 负责视频播放、题库答题、跳章；
- 如果一个页面同时跑多个同类脚本，会出现**重复点“下一节”、一次跳两章**，请只保留一份；
- 测验类脚本依赖页面上的“重做”入口；只允许考一次的测验无法重做，脚本会提示后停止。
