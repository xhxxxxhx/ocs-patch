# OCS 补丁 · 学习通 / 超星 刷课脚本

**OCS 补丁**：两个配合 [OCS 网课助手](https://docs.ocsjs.com) 使用的用户脚本，专治 OCS 自己搞不定的两种卡死：

1. **任务点完成后不跳下一章** —— 页面渲染慢导致点击落空时自动重试；长时间无进展按级自救。
2. **章节测验答错** —— 从成绩页读出正确答案后重做重填，循环到满分；题库没答案时按看门狗自动蒙题并交卷。

## 脚本说明

| 文件 | 作用 | 版本 |
|---|---|---|
| `cx-auto-next.user.js` | 任务点完成后自动跳下一章；跳转落空重试；连续 10 分钟无推进时：视频暂停→点播放、切学习测验、强制点下一节、整页刷新、红条告警 | 1.1.0 |
| `cx-quiz-retry.user.js` | 章节测验：读成绩页正确答案 → 重做 → 填对 → 再交，直到满分；题都选完 60 秒不交卷自动点提交；90 秒没人答题自动蒙一轮再交 | 1.6.0 |

## 安装

需要先装一个用户脚本管理器，二选一：

- [脚本猫 ScriptCat](https://scriptcat.org/)（推荐，Edge/Chrome）
- [Tampermonkey 篡改猴](https://www.tampermonkey.net/)

然后任选一种方式安装脚本：

**方式 1：从本仓库 raw 链接安装**

在浏览器安装好管理器后，直接打开对应文件的 raw 地址，管理器会弹出安装页：

```
https://raw.githubusercontent.com/xhxxxxhx/xxx/main/cx-auto-next.user.js
https://raw.githubusercontent.com/xhxxxxhx/xxx/main/cx-quiz-retry.user.js
```

**方式 2：本地导入**

下载 `*.user.js` 文件，拖进管理器的管理面板，或新建脚本后粘贴内容保存。

## 工作原理

### cx-auto-next.user.js（自动下一章）

学习通章节页上，任务点做完后由页面自己跳到下一节。但新版页面渲染慢时，脚本点“下一节”会**点了个空**，然后一直停在“本节已完成”，看起来像卡死。

脚本做的事：任务点判断为完成后，先等 8 秒让页面自己跳；没跳就走五条路依次尝试（弹窗按钮 → 底部按钮 → 按文字找 → 章节列表下一项 → `PCount.next()`），失败每隔 7 秒重试，最多 10 次。

连续 10 分钟没有任何推进（换章、视频在播、题目在做都算推进）时，按级自救：

1. 视频被暂停 → 自动点播放；
2. 切到「学习测验」→ 让刷分脚本处理；
3. 强制点“下一节”；
4. 整页刷新，让 OCS 重新注入继续跑（5 分钟内不重复刷）；
5. 仍不动 → 右下角红条告警（多是被测验限次 / 闯关锁章 / 人脸识别挡住）。

### cx-quiz-retry.user.js（测验刷分）

成绩页会给出每道题的“正确答案”，脚本用它把分数刷上去：

1. 第一轮交给 OCS 题库作答、交卷（脚本不抢）；
2. 成绩页出现后，按题号抓「我的答案 / 正确答案 / 得分」，存进 localStorage；
3. 没满分 → 点“重做”→ 按正确答案重填 → 再交；循环，最多 6 次；
4. 成绩页不给答案时，改为“蒙”另一个选项（避开上一轮选过的）。

两个看门狗兜住“卡住”的情况：

| 现象 | 处理 |
|---|---|
| 题都选完了，但 60 秒没交卷 | 自动点「提交」并确认 |
| 90 秒没人答题（题库没答案，OCS 干等） | 自动蒙一轮然后交卷 |
| 重做弹窗没点动 | 不消耗次数，下一轮再试 |

## 使用建议

- 两个脚本都是给 **OCS 网课助手** 打配合的，OCS 负责视频播放、题库答题、跳章；
- 如果一个页面同时跑多个同类脚本，会出现**重复点“下一节”、一次跳两章**，请只保留一份；
- 测验类脚本依赖页面上的“重做”入口；只允许考一次的测验无法重做，脚本会提示后停止；
- 页面左下角/右下角会出现两个小徽标（`[自动下一章]`、`[自动刷分]`），显示脚本当前在等什么，排查时看它最快。

## 常见问题

**Q：装了没反应？**
看页面右下角有没有蓝色徽标；没有就说明脚本没注入（检查管理器的脚本是否启用、`@match` 是否包含当前域名）。

**Q：会不会一次跳两章？**
只装一份就不会。装了两份（名字不同但功能相同）会重复点击，务必删掉多余的。

**Q：测验分数没刷上去？**
先看徽标写的是什么：`没有“重做”入口` = 该测验只允许考一次；`重做没点动` = 弹窗被拦，脚本会自动重试；`已交 N 次仍未满分` = 达到重试上限（默认 6 次）。
